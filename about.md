# Input Buffer

When you let go of a click, the game keeps it held for a few extra frames
(2 to 8, set in the mod settings). Taps that land slightly too early for a
jump, orb or pad still register.

- **Extra Frames**: 2-8, measured at 60 FPS (about 33-133 ms).
- **Buffer Platformer Movement**: also delays left/right releases.
- **Safe Mode** (on by default): plays levels in test mode so runs with the
  buffer aren't saved as real completions.
